## 4. COMANDOS EXACTOS DEL PIPELINE

> Rutas en MSYS (`/c/Users/USER/Desktop/belentani_Omega-live/`).
> Ajusta las rutas de modelos/bins a tu entorno. Todo corre en local; ninguna señal sale del navegador.

### 4.1 RVC — clonación y transporte de voz
```bash
# 1) Extraer pitch (base: stems ya separados)
rvc_python infer \
  --model assets/rvc/belentani-v1.pth \
  --index assets/rvc/belentani-v1.index \
  --input assets/audio/raw-vocal.wav \
  --output assets/audio/vocal-rvc.wav \
  --f0method rmvpe --pitch 0 --filter_radius 3 --protect 0.33

# 2) Normalizar salida
ffmpeg -i assets/audio/vocal-rvc.wav -ar 44100 -ac 1 -af loudnorm=I=-16:TP=-1.5:LRA=11 assets/audio/vocal-norm.wav
```

### 4.2 ComfyUI + Wan2.2 — imagen y vídeo generativo
```bash
# Workflow en ComfyUI (exporta el JSON del flujo)
python ComfyUI/main.py --listen 127.0.0.1 --port 8188 &

# Lanzar un render Wan2.2 (image-to-video) desde API
curl -s -X POST http://127.0.0.1:8188/prompt \
  -H 'Content-Type: application/json' \
  -d @assets/workflows/wan22-act1.json

# Convertir secuencia .mp4 -> poster .webp + hero
ffmpeg -i assets/media/wan22-act1.mp4 -vframes 1 -q:v 2 assets/media/act1-poster.webp
```

### 4.3 Audio — Ardour + Surge XT (mezcla y máster)
```bash
# Abrir la sesión del EP
ardour6 assets/audio/judas-experience.ardour &

# Surge XT como plugin de sintetización (VST3) — invocar dentro de Ardour
# Exportar stems por track T01..T06 a 48k/24bit
```

### 4.4 Remotion — lyric video
```bash
# Instalar deps (una vez)
cd remotion/judas-experience && npm install

# Render del lyric video (frame por frame)
npx remotion render src/JudasExperience.tsx judas-lyric.mp4 \
  --props=src/props.json --codec=h264 --crf=18 --concurrency=4

# Versión webm + VTT subtítulos
npx remotion render src/JudasExperience.tsx judas-lyric.webm --codec=vp9
```

### 4.5 FFmpeg — normalización y ensamblado final
```bash
# Cortometraje 5:12 con audio mezclado + subtítulos
ffmpeg -i assets/video/judas-clip-video.mp4 \
       -i assets/audio/judas-clip-audio.wav \
       -c:v libx264 -pix_fmt yuv420p -preset slow -crf 18 \
       -c:a aac -b:a 192k -shortest \
       -map 0:v:0 -map 1:a:0 \
       assets/media/judas-experience-clip.mp4

# Poster + normalize hero
ffmpeg -i assets/media/judas-floating-hero.mp4 -vframes 1 -q:v 2 assets/media/judas-poster.webp
```
