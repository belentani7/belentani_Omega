# Belentani Omega — el universo artístico

Punto de entrada de la obra de **Pedro Belentani**: música, código y tecnología creativa
en un solo organismo.

**En línea:** <https://belentani.es>

## Qué es

Este repositorio es el **sitio oficial** y el nodo central del universo artístico. Las demás
webs no son proyectos sueltos: son puertas distintas a la misma obra. Aquí está el mapa.

## El universo en un vistazo

## Estructura

```
assets/       recursos gráficos y sonoros
css/          hojas de estilo
js/           lógica del sitio
ecosistema.html   vista del ecosistema completo
ecosystem.json    datos del ecosistema
universo.json     mapa de nodos y conexiones
CNAME         dominio propio (belentani.es)
```

## Publicación

GitHub Pages con dominio propio vía `CNAME`. El sitio vive en la raíz del repositorio.

## Regla del universo
