STUDIO READY

04 / PROCESO / HERRAMIENTAS

El studio
muestra el cómo.

Un laboratorio para entender decisiones: qué herramienta sirve para cada capa y qué parte sigue siendo criterio humano. Aquí no se esconde el motor, se enseña.

PIPELINE VIVO

Cada capa tiene su herramienta, no su atajo.

01

Texto y archivo

Corpus local, narrativa, definiciones, letras en cuatro idiomas y ledger. La estructura editorial llega antes que el efecto. data/drive-corpus/ es la fuente de verdad.

02

Imagen y vídeo

Fotografía, posters y hero WebGL. ComfyUI + Wan2.2 generan planos; FFmpeg los normaliza a .webp y .mp4 con poster.

03

Voz

RVC clona y transporta la voz original. Ardour + Surge XT mezclan; 432/528 Hz son guía simbólica, no terapéutica.

04

Render y código

Three.js r128 con UnrealBloomPass, GSAP + ScrollTrigger, Lenis para scroll, GLSL shaders. El navegador es el escenario.

05

Publicación

HTML semántico estático, Service Worker, manifest. Sin frameworks de runtime: el archivo carga y se conserva.

STACK TÉCNICO

Herramientas.

Lo que se usa hoy. Cada entrada es una decisión, no una moda.

  • Three.js r128 WebGL + bloom; canvas del hero y escenas.
  • GSAP 3.12 + ScrollTrigger movimiento y secuencia por scroll.
  • Tone.js 14.8 audio generativo, Beat Forge, frecuencias.
  • Lenis scroll suave.
  • Canvas 2D motor de 60.000 partículas Genesis.
  • GLSL diez shaders propios.
  • RVC clonación y transporte de voz.
  • ComfyUI + Wan2.2 imagen y vídeo generativo.
  • Ardour + Surge XT DAW y sintetizador.
  • Remotion lyric videos por código.
  • FFmpeg normalización y codificación.

CÓDIGO / MUESTRA

Cómo suena una frecuencia.

El motor de partículas del hero y el núcleo de Tone.js no son decoración: son la misma idea — una herida que se organiza. Recorte representativo:

// js/18-singularity-hero.js — núcleo del campo
const COUNT = 60000;            // partículas del Genesis Engine
const geo = new THREE.BufferGeometry();
geo.setAttribute('position',
  new THREE.BufferAttribute(initField(COUNT), 1));
const mat = new THREE.ShaderMaterial({
  uniforms: { uTime: { value: 0 }, uPressure: { value: 0.0 } },
  vertexShader: VERT, fragmentShader: FRAG,
  blending: THREE.AdditiveBlending, transparent: true
});
renderer.setAnimationLoop(t => {
  mat.uniforms.uTime.value = t * 0.001;
  mat.uniforms.uPressure.value = cursorPressure();
});
